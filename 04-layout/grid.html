CSS Tradicional

Para construir a grade manualmente precisamos controlar:

  • float;
  • largura de cada elemento;
  • cálculo da largura;
  • margem horizontal;
  • margem vertical;
  • remoção da margem do terceiro elemento;
  • limpeza do fluxo com clear.
.card {
    float: left;
    width: calc(33.333% - 14px);
    margin-right: 20px;
    margin-bottom: 20px;
}

.card:nth-child(3n) {
    margin-right: 0;
}

.container::after {
    content: "";
    display: block;
    clear: both;
}

CSS Grid

Com Grid, a estrutura da grade é definida diretamente no container. 

.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

Resultado: três propriedades descrevem praticamente toda a estrutura do layout.
