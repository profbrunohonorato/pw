CSS Clássico vs Flexbox

Experimento

O objetivo é criar quatro elementos lado a lado, ocupando igualmente o espaço disponível.

  1. Execute o código como está.
  2. Observe o CSS utilizado na seção OPÇÃO 1 - CSS CLÁSSICO.
  3. Comente todo o código da OPÇÃO 1.
  4. Descomente o código da OPÇÃO 2 - FLEXBOX.
  5. Execute novamente.
  6. Compare a quantidade de código necessária para obter praticamente o mesmo resultado.

Observe: com Flexbox, grande parte da responsabilidade pelo posicionamento dos elementos passa para o container.

Compare

Na solução clássica precisamos controlar:

  • display: inline-block;
  • largura dos elementos;
  • cálculo da largura;
  • margens;
  • remoção da margem do último elemento;
  • alinhamento vertical;
  • espaçamento causado pelo inline-block.

Com Flexbox:

.container {
    display: flex;
    gap: 20px;
}

.card {
    flex: 1;
}

O navegador passa a controlar automaticamente a distribuição dos elementos.
