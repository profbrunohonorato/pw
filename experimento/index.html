Experimento

  1. Abra esta página no navegador.
  2. Reduza a largura da janela até simular a tela de um celular.
  3. Aumente lentamente a largura da janela.
  4. Observe as mudanças quando a largura passa por 600px e 900px.
  5. Abra o DevTools do navegador e utilize o modo de simulação de dispositivos móveis.
  6. Depois, comente todo o bloco MOBILE FIRST.
  7. Descomente o bloco desktop first localizado no final do CSS.
  8. Compare as duas estratégias.

Mobile First

Na abordagem Mobile First, começamos pelo layout mais simples: 

.cards {
    display: grid;
    grid-template-columns: 1fr;
}

Depois adicionamos recursos conforme a tela aumenta: 

@media (min-width: 600px) {

    .cards {
        grid-template-columns: repeat(2, 1fr);
    }

}

@media (min-width: 900px) {

    .cards {
        grid-template-columns: repeat(3, 1fr);
    }

}

Observe os breakpoints

Neste exemplo temos três situações:

  • Menos de 600px: 1 coluna.
  • 600px ou mais: 2 colunas.
  • 900px ou mais: 3 colunas.

O CSS vai sendo incrementado conforme existe mais espaço disponível.

Mobile First vs Desktop First

Mobile First normalmente utiliza: 

@media (min-width: ...)

A pergunta é: "O que deve mudar quando a tela ficar maior?"

Desktop First normalmente utiliza: 

@media (max-width: ...)

A pergunta passa a ser: "O que preciso remover ou reorganizar quando a tela ficar menor?"

Conclusão

Mobile First não significa apenas "fazer um site que funciona no celular".

Significa desenvolver primeiro para o ambiente mais restrito e adicionar complexidade progressivamente conforme existe mais espaço.
