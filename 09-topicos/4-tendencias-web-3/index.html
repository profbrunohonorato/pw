HTML na evolução da Web

“Web 3.0” pode se referir à web semântica e aos dados conectados; “Web3” costuma designar aplicações descentralizadas. Esses termos não são uma versão nova do HTML.

Conteúdo estruturado para pessoas e máquinas. Esta página tem JSON-LD descrevendo um material didático; inspecione o código-fonte.

Plataforma nativa

Dialog, popover, Web Components e recursos offline reduzem a necessidade de bibliotecas em algumas tarefas. São recursos da plataforma Web, não exclusivos da Web3.

Descentralização

Progressive Web App: uma página offline

Ative manualmente um service worker restrito a esta pasta. Após a instalação, recarregue a página; depois teste o modo offline no DevTools. Isso não é uma conexão a blockchain.

O recurso ainda não foi ativado nesta visita.

Service workers precisam de HTTPS ou localhost. A remoção exclui apenas o registro e o cache desta aula.

Carteira não é login automático

Em uma aplicação Web3, a página solicita uma conta ao provedor com autorização do usuário. Autenticação exige um desafio verificável; transferir valores exige outra autorização. Este exemplo não solicita contas nem assina transações.
