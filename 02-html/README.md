# Exemplos HTML para aula

Cada diretório contém um `index.html` independente, pronto para abrir no navegador, testar no W3Schools/W3C e publicar via GitHub Pages.

## Exemplos

1. Títulos e parágrafos
2. Formatação e blockquote
3. Links
4. Imagens
5. Iframe
6. Head, meta, CSS, JavaScript e base
7. Formulário básico
8. Elementos de formulário
9. Canvas
10. SVG
11. Multimídia
